# CCAR-F Logistics

## Access path

- Certification is open to organizations in the **Claude Partner Network** and counts toward partner program standing. Individuals without a qualifying org can request access via the Skilljar portal and start all free prep courses immediately. Broader public access expected later 2026 (no confirmed timeline).
- **Access, not exam difficulty, is the bottleneck** - join the Claude Partner Network (free) before planning a sit date.

## Exam-day mechanics

- **Name must match government ID exactly** - mismatch at check-in = no entry + fee forfeited. Correct via certifications-support@anthropic.com, subject "Name Correction Request", >=24h before.
- **Reschedule/cancel >=48h** before the appointment (Pearson account or live agent); inside 48h = fee forfeited. (The free-prep site says 24h; Pearson's policy is 48h - use 48h.)
- **Retakes**: 14 days -> 30 days -> 90 days after each failed attempt; max 4 attempts per exam per rolling 12 months.
- **Recertification**: on-time = free, non-proctored; lapsed = full resit.
- Switching delivery mode (OnVUE <-> test centre): cancel and reschedule into the other mode, same 48h rule.

## Official materials (free, gated via Skilljar)

- Anthropic Partner Academy prep courses
- Official 60-question practice exam
- Three PDFs to read before exam day: Exam Guide, Certification T&Cs, Anthropic Certification Exam Policy

## Credential

- Digital badge via Credly, issued by Anthropic. Badge maps to an official 11-skill taxonomy: AI System Design, Claude Agent SDK, Claude Code configuration, Context Management, Generative AI Architecture, LLMs, Multi-Agent Orchestration, Production reliability, Prompt Engineering, Structured output, Tool & MCP design. Use as a study checklist: if you cannot explain a tag, it is a study gap.
