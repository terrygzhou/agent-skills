# claude-cert skills bucket

Skills for Anthropic Claude certification preparation: one skill per certification track,
plus shared family references. Each skill does two things - it makes an agent skillful
at the role's actual work (the discipline, not trivia) and it prepares for that track's
exam. Track-level routing (which cert for which role) lives in the shared family
reference.

## Skills

- [claude-ccao-f](ccao-f/SKILL.md) - Claude Certified Associate - Foundations (CCAO-F):
  the no-code productivity credential - structured prompting, judging output, model and
  product selection, configuring Claude Projects, responsible use.
- [claude-ccdv-f](ccdv-f/SKILL.md) - Claude Certified Developer - Foundations (CCDV-F):
  production-grade Claude applications, agents, and workflows - API mechanics, prompt
  and tool engineering, model/cost management, MCP servers, evals, security.
- [claude-ccar-f](ccar-f/SKILL.md) - Claude Certified Architect - Foundations (CCAR-F):
  the only scenario-based exam - agentic architecture, tool/MCP design, Claude Code,
  prompt engineering, context and reliability.
- [claude-ccar-p](ccar-p/SKILL.md) - Claude Certified Architect - Professional (CCAR-P):
  owning a production Claude system end to end - enterprise integration, evaluation,
  governance/safety/risk, stakeholder communication, lifecycle, team enablement.

## Shared references

- [references/claude-cert-family.md](references/claude-cert-family.md) - the four-cert
